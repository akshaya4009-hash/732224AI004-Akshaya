- Create a workflow
- Manual Trigger : the workflow starts when you click the execute workflow button.
- Web request : it sends an http request to the n8n blog URL.
- Data fetching : the system uses the get method.
- The fetched html data is sent directly to the next node.
- The html extract node receives the raw webpage data.
- The specific data you need is pulled out and ready for the next step.
