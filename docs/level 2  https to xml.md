- Create a workflow
- Manual Start: You trigger the workflow by clicking Execute workflow.
- API Request: It sends an HTTP GET request to the API (pokeapi.co).
- Data Retrieval: The system fetches specific data about Pokémon in JSON format.
- Format Conversion: The XML node takes that JSON data to transform it.
- XML Output: The final result is converted into XML format for your use.
